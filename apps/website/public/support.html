Support

Most problems are covered below. If you're still stuck, email support@bloomlauncher.example with a description and your launcher log (see the last question).

Signing in

“This Microsoft account doesn't own Minecraft: Java Edition”

MOTION checks ownership with Minecraft's services. Make sure you're using the account that bought the game. Game Pass players must launch Java Edition once from the official launcher to create a profile.

“Please accept the Xbox Terms of Service” / “child account” / “no Xbox profile”

These come from Xbox Live. Sign in at xbox.com once to accept the terms or create a profile. Child accounts must be added to a Microsoft family by an adult who allows online play.

“Minecraft rejected this launcher's sign-in”

The build you're using was made with a Microsoft app registration that Mojang hasn't approved. Download MOTION from this site.

Can I play offline?

Yes, for singleplayer, once your account has been verified online at least once. Multiplayer needs an online session.

Launching

Minecraft crashes right after starting

Open the installation's Logs tab. The most common cause is a mod for a different Minecraft version or loader — the Content tab marks those in red. Disable recently added mods to narrow it down.

The first Forge or NeoForge launch takes a long time

MOTION runs the loader's official installer steps (patching the game) on the first launch. This takes one to three minutes and only happens once per version.

“Java was not found” or “needs Java 21”

MOTION downloads the Java version each Minecraft release needs. If you set a custom Java path, remove it in the installation's settings so MOTION can use the right one.

“A downloaded file was corrupted” or the game won't start after an update

Use Repair in the installation menu. MOTION re-checks every file against its checksum and downloads anything damaged.

Not enough disk space

MOTION checks free space before downloading. Free some space, or move installations to another drive with a custom game directory.

My antivirus flagged MOTION or a mod

Official MOTION installers are code-signed. MOTION never runs code from mods itself; mods only run inside Minecraft. Only install mods you trust — Modrinth reviews uploads, files from elsewhere are your responsibility.

Performance

Will MOTION double my FPS?

No launcher can promise that. Performance mods like Sodium often help a lot, but results depend on your PC, settings, world and mods. MOTION shows measured data instead of estimates.

How much memory should I allocate?

MOTION recommends a value based on your RAM and mod count. More isn't better: oversized heaps cause longer garbage-collection pauses.

How do I undo a preset?

Performance → Backups. Every preset change is backed up first and can be restored.

Premium and billing

I paid but Premium isn't active

It usually activates within seconds. Press Refresh on MOTION's Premium page, or Restore purchases on your account page.

How do I cancel or change my plan?

MOTION → Premium → Manage subscription opens Stripe's billing portal, where you can cancel, switch plans, update your card and download invoices.

Where are my files and logs?

Installations, worlds and mods: %APPDATA%\com.bloomlauncher.desktop\instances. Launcher logs: %LOCALAPPDATA%\com.bloomlauncher.desktop\logs. Game logs: each installation's logs folder (also shown in the Logs tab). Logs never contain your passwords or tokens.
