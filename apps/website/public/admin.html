Capes

Publish capes for BLOOD players. Use Minecraft's cape layout: 64×32 (or an HD multiple: 128×64 … 1024×512). PNG, JPG, WebP or an animated GIF (up to 64 frames); for animations you can also upload a PNG strip with the frames stacked top to bottom. Only players using BLOOD see these capes.

Tags

Give a player a tag shown before their name in game, like [OWNER]. Only BLOOD players see tags. The player must have signed in to the BLOOD launcher once. Leave the tag empty to remove it.

All keys

Keys are listed by their last five characters. Reset PC lets the key be activated on any PC again (for a player who can't wait 24 hours). Disable stops it working everywhere.
