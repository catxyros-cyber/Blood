Installing

  1. Run Bloom_x.y.z_x64-setup.exe. It installs for your user account only — no administrator rights needed.
  2. If Windows shows "Windows protected your PC", choose More info → Run anyway. This appears for new apps until they build reputation with Microsoft SmartScreen; official MOTION installers are code-signed.
  3. MOTION uses Microsoft Edge WebView2, which is already part of Windows 11 and most Windows 10 PCs. If it's missing, the installer downloads it.

Updating

MOTION checks for updates when it starts and installs them after you confirm. Every update is signed, and MOTION refuses an update whose signature doesn't match.

Uninstalling

Open Settings → Apps → Installed apps, find MOTION and choose Uninstall. Your installations and worlds stay in %APPDATA%\com.bloomlauncher.desktop until you delete that folder yourself.

System requirements

  • Windows 10 (version 1809+) or Windows 11, 64-bit
  • A Microsoft account that owns Minecraft: Java Edition
  • 4 GB RAM minimum, 8 GB+ recommended for modded play
  • About 1 GB of disk space per Minecraft version, plus mods and worlds
  • An internet connection for the first launch of each version
MOTION doesn't include any Minecraft game files. They're downloaded from Mojang after you sign in with an account that owns the game.
