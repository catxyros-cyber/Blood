MOTION Performance

MOTION recommends optimization mods like Sodium, Lithium and FerriteCore only when Modrinth has a version that matches your installation, detects mods that fight over the renderer, and suggests safe memory settings for your PC.

Its analytics are measured, not invented: heap usage and garbage-collection pauses come straight from the JVM's own log, and launch times from the game's output.

Real-world FPS depends on your hardware, game settings, the world you're in and the mods you install. MOTION never promises a specific frame rate.

MOTION Client

An optional in-game mod for Fabric, Quilt and NeoForge on Minecraft 1.21.1. Press Right Shift for a menu with custom skyboxes, drifting cherry petals, decorative rain and snow, a drag-and-drop HUD editor and shareable visual profiles.

It's purely visual and client-side: it never changes gameplay, and it pauses its sky and fog when a shader pack takes over. Set it up from the launcher's Customize page with a live preview.

Get started in a minute

  1. Download and install MOTION. No developer tools, no Java install — MOTION gets the right Java for each Minecraft version.
  2. Sign in with Microsoft. You sign in on Microsoft's own page. MOTION never sees your password.
  3. Create an installation and press Play. Add mods from Modrinth or your own files, then apply a performance preset.
